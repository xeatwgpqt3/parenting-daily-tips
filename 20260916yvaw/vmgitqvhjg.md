# 怀孕多久要去医院建档需要什么资料，怀孕建档是什么意思

> 更新时间：2026-09-16 (UTC+8)

育龄的妇女一旦发现自己怀孕，首先一件事，除了是要去到相关的妇产科医院进行一系列检查和确诊之外，就是一定要到相关的社区卫生服务中心去办理一下相关的卡，这样的话，才可以带着这围产卡到医院去进行产检，对以后的各个方面检查都是有帮助的，所以怀孕多久要去医院建档需要什么资料?
怀孕多久要去医院建档需要什么资料
　　孕妇建档一般需要带上身份证，参加医疗保险的要带上医保卡，有些医院还要求带准生证。当然，各地医院的规定可能都不一样，所以孕妇朋友在去医院之前最好打电话咨询清楚，避免因漏带证件来回奔波。

　　提醒：孕妇朋友选择在哪家医院生产，就在哪家医院建立档案，最好不要中途转院，以确保信息的全面性和连续性。以便更好地应对孕期发生的状况。

　　妇妇科检查具体的项目大致有六类，他们分别是白带常规检查、阴道镜检查、B超检查、宫颈癌筛选检查、乳腺组织检查、尿常规检查。孕妇在体检之前的一天不能有性行为，也不能在阴道使用药物。

　　孕妇妇科检查的时候可能需要做外阴检查，这主要是检查是否有生殖器疣的存在，还可以检查出是否有hpv病毒感染。浏览发现有这些疾病应当立即进一步检查，然后确定是否治疗。

　　孕妇妇科检查的时候需要做阴道镜检查，这主要是检查是否有宫颈糜烂。阴道B超检查主要是了解阴道以及卵巢的具体情况。阴道B超镜检查特别方便，不用憋尿，也不会有不适的感觉，整个检查过程最多二十分钟。
围产卡基本信息
　　子宫底高度：检查子宫底高度，可以了解的发育情况。正常妊娠时，子宫底高度的增长有一定规律性，妊娠16周子宫底约达脐与耻骨联合中间，妊娠24周约在脐稍上，妊娠36周约近剑突。方法简便，可了解的成熟和大小。

　　听胎心音：听胎心率来判断是否有宫内窒息，这是常用有效方法，应注意胎心音的节律性是否忽快忽慢等，正常胎心音120～160次/分，如果胎心音160次/分以上或持续100次/分都表示宫内缺氧，应及时治疗。

　　观察胎动：正常胎动每小时不少于3次。也可连续测定12小时内胎动总数，可早晨、中午、晚上各测1小时胎动数，相加总数再乘4，等于12小时胎动数。如果12小时内的胎动数在30次以上为正常，说明有较好的储备力;若下降至20次以下，提示宫内缺氧。在缺氧死亡前的12～48小时，常先有胎动明确减少和消失。
